### ISSUE-003 — Bestiario topbar button triggers West navigation instead of opening panel
**Severity:** Critical  
**Category:** Functional  
**Repro:**
1. Start game at Oakhaven
2. Click "Bestiario" button in the topbar navigation
3. Observe: player moves west to "The Drunken Dragon" instead of Bestiario panel opening

**Expected:** Bestiario panel opens (modal showing discovered enemies)  
**Actual:** The click registers as a West navigation movement. Multiple clicks trigger multiple travel events ("Mercader Misterioso"). The nav button is also not interactable via the browse tool's click command.

The `data-panel="bestiary"` button in the topbar nav is either hidden behind or overlapping with the West ("O") navigation button. The click coordinates for the Bestiario button in the desktop topbar are being intercepted by the sidebar/mobile nav West button (x=576).

**Screenshot:** `screenshots/11-bestiario-panel.webp`

### ISSUE-004 — navCrafting i18n key not resolved — button label shows raw key name
**Severity:** High  
**Category:** i18n  
**Location:** Topbar navigation, "⚒️ navCrafting" button  
**Repro:**
1. Observe the topbar navigation bar
2. The 8th nav button reads "⚒️ navCrafting"

**Expected:** Should read "⚒️ Forja" (in Spanish) or equivalent localized text  
**Actual:** HTML contains `<span data-i18n="navCrafting">navCrafting</span>` — the translation key `navCrafting` has no matching entry in the i18n dictionary, so the key name is displayed raw.

**Evidence:** HTML inspection confirms `data-i18n="navCrafting"` with fallback text = key name.

## Additional Observations

- **Movement cooldown bug**: After multiple accidental navigation clicks (caused by Issue-003/Bestiario button), the game entered a permanent "Procesando tu movimiento... espera un momento." state with all navigation buttons disabled. Required page reload.
- **Shop requires location**: The Quick Shop button (🛒 in sidebar actions) shows "Necesitas estar en una tienda" at Oakhaven. Users must navigate to a shop-type location to access the shop. This is by design but the message is clear.
- **Quest acceptance dialog state**: After clicking "Aceptar misión", the NPC badge correctly changes from "DISPONIBLE" to "EN PROGRESO" within the NPC dialog. The failure is in the quest log not updating.

## Top 3 Things to Fix

1. **Quest acceptance not registering** (ISSUE-006): Core game loop is broken — players accept quests but can't track them. No active quest → no quest progression → no game progression.

2. **Bestiario button navigates west instead of opening panel** (ISSUE-003): Every click on the Bestiario topbar button moves the player and triggers travel events. This also causes the movement cooldown to stack up and permanently lock navigation.

3. **NPC quest text shows "Desconocido"** (ISSUE-001): The `{{npc}}` template variable isn't resolving in the NPC dialog's quest description. Players see "Habla con Desconocido" which is confusing and breaks immersion.
